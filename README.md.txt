# Лабораторная работа №2. Обучение без учителя

Реализация лабораторной работы по дисциплине **«Машинное обучение»** для кафедры «ИПМ Ростсельмаш» (ДГТУ).

## 🚀 Описание проекта
Работа посвящена анализу многомерных данных методами понижения размерности и автоматической группировке объектов со сложной нелинейной геометрией в пространстве признаков.

**Выполнил:** Студент группы ИПБП41  
**Вариант:** № 7  

## 📦 Структура проекта
* `data/` — исходные датасеты по варианту.
* `src/main_pipeline.py` — полный конвейер обработки данных (декомпозиция PCA/SVD/ICA и 12 алгоритмов кластеризации).

## 💻 Использованные библиотеки
* `scikit-learn` — реализация алгоритмов декомпозиции и кластеризации.
* `pandas`, `numpy` — считывание, очистка и матричные вычисления.
* `matplotlib`, `seaborn` — построение матриц разброса, тепловых карт и Biplot-проекций.

## 📊 Краткие результаты
1. **Понижение размерности:** Выявлена сильная мультиколлинеарность между признаками `a` и `b` (r = 0.854). Метод PCA показал, что первые 3 компоненты удерживают более 77% дисперсии выборки.
2. **Кластеризация:** Центроидные методы (K-Means) оказались неэффективны для невыпуклых структур. Наилучшее качество сегментации и фильтрации аномалий показал алгоритм `HDBSCAN`.
